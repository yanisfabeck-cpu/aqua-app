# Aqua Map

Alle kostenlosen Trinkbrunnen, Wasserspender und Refill-Stationen in Luxemburg auf einer Karte, als App fürs Handy und den Computer.

**App öffnen:** https://yanisfabeck-cpu.github.io/aqua-app/

## Funktionen

- **Karte:** alle Wasserstellen live aus OpenStreetMap, mit Ortsnamen, Filtern, Suche, „In meiner Nähe“ und Routenplanung
- **Rätsel:** Wasser-Rätsel, Wasser-Quiz und Buchstabensalat mit Punkten
- **Scannen:** QR-Codes an Wasserstellen scannen und Besuchspunkte sammeln
- **Eintragen:** fehlende Wasserstellen als Hinweis an OpenStreetMap melden
- **Profil:** Spitzname, Punkte, Level und Abzeichen (nur auf dem eigenen Gerät gespeichert)

## Installieren

- **Android (Chrome):** Adresse öffnen und auf „App installieren“ tippen
- **iPhone (Safari):** Teilen > „Zum Home-Bildschirm“ > „Hinzufügen“
- **Computer (Chrome/Edge):** Installieren-Symbol in der Adressleiste
